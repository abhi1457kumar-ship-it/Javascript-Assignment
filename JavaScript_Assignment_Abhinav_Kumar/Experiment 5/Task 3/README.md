# Experiment 5 — Task 3

## What it does

Filter marks to keep values of 60 or above.

## Steps

1. Create the array marks with 72, 85, 45 and 90.
2. Use filter with a function that returns true when mark >= 60, and store the result in newMarks.
3. Print newMarks.

## Files

- README.md
- task3.html
- task3.js

## How to run

Open task3.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints the filtered array [72, 85, 90].
