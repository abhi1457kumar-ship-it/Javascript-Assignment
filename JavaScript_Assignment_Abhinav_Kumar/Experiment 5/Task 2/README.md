# Experiment 5 — Task 2

## What it does

Use forEach to print each subject in an array.

## Steps

1. Create the array subjects with "Maths", "Science" and "English".
2. Use forEach to call a function for every subject.
3. Print each subject inside the function.

The console prints Maths, Science, and English on separate lines.
