# Experiment 5: Arrays, Array Methods and Nested Arrays

## Aim

To create an array, read its items, use forEach and filter, and read a value from an array inside an array.

## Software / Tools Required

Web browser (Google Chrome / Microsoft Edge / Firefox) with the developer console (F12); Node.js; a code editor such as VS Code.

## Theory

An array stores many values in one variable, and its items are read by an index that starts from 0. The length property gives the number of items. forEach() runs a function once for every item. filter() creates a new array with only the items that pass a test, and the original array stays unchanged; A nested array is an array inside another array, so a value is read with two indexes, such as grid[1][2].

JavaScript programs were written to create arrays, to read their items, to use forEach and filter, and to read a value from a nested array.

## Viva-Voce Questions
