# Experiment 5 — Task 4

## What it does

Read a value from a nested array using two indexes.

## Steps

1. Create the array grid that contains the arrays [1, 2, 3] and [4, 5, 6].
2. Read the value in row 2 and column 3 using grid[1][2].
3. Print the value.

## Files

- README.md
- task4.html
- task4.js
- screenshot_task4.png

## How to run

Open task4.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints 6.
