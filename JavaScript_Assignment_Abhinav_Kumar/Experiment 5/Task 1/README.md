# Experiment 5 — Task 1

## What it does

Create a marks array and print its length and first value.

## Steps

1. Create the array marks with 72, 85, 64 and 90.
2. Print "Number of items:" followed by marks.length.
3. Print "First mark:" followed by marks[0].

## Files

- README.md
- task1.html
- task1.js
- screenshot_task1.png

## How to run

Open task1.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Number of items: 4 and First mark: 72.
