# Experiment 8 — Task 1

## What it does

Extend Person with a Teacher class and call the inherited greeting method.

## Steps

1. Define the class Person with a constructor that saves name and a method greet() that returns "Hi, I am " joined with the name.
2. Define the class Teacher that extends Person; its constructor calls super(name) and saves the subject.
3. Create the object teacher using new Teacher("Anita", "Maths").
4. Print teacher.greet().

## How to run

Open task1.html in Chrome, Edge, or Firefox and press F12 to check the Console.

The console prints Hi, I am Anita.
