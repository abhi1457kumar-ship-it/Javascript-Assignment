# Experiment 8 — Task 3

## What it does

Compose a Car from an Engine object and print the start message.

## Steps

1. Define the class Engine whose constructor saves the power.
2. Define the class Car whose constructor creates an Engine from the power and stores it in this.engine.
3. Add the method start() that returns "Car starts with ", the engine power and " HP".
4. Create the object car using new Car(150).
5. Print car.start().

- README.md

## How to run

Open task3.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Car starts with 150 HP.
