# Experiment 8 — Task 2

## What it does

Check incorrect and correct PIN values with a Locker method.

## Steps

1. Define the class Locker whose constructor sets pin = 1234.
2. Add the method checkPin(number) that returns true if number === this.pin, otherwise false.
3. Create the object locker.
4. Print locker.checkPin(1111) and locker.checkPin(1234), one on each line.

Open task2.html in Chrome, Edge, or Firefox and press F12 to check the Console.

The console prints false, then true.
