# Experiment 8: Inheritance, Methods and Composition

## Aim

To use extends to make a child class, to write a method that checks a value, and to place one object inside another.

## Software / Tools Required

Web browser (Google Chrome / Microsoft Edge / Firefox) with the developer console (F12); Node.js; a code editor such as VS Code.

## Theory

Inheritance lets a child class reuse the properties and methods of a parent class using the extends keyword. The super() call inside the child constructor runs the parent constructor. A method can check a value and return true or false. In composition, an object is stored inside another object, which gives a has-a relationship, such as a Car that has an Engine.
