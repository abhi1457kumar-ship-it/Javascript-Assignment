# Experiment 7: Constructor Functions and Classes

## Aim

To create objects with a constructor function and with an ES6 class, and to add a method through the prototype.

## Software / Tools Required

Web browser (Google Chrome / Microsoft Edge / Firefox) with the developer console (F12); Node.js; a code editor such as VS Code.

## Theory

A constructor function is a normal function used with the new keyword to create objects; this refers to the new object. An ES6 class is a modern way to write the same idea, with a constructor method and other methods inside the class. Every constructor function has a prototype object, and a method added to it is shared by all the objects created from that constructor.
