# Experiment 7 — Task 1

## What it does

Create a Student object with a constructor function and print its properties.

## Steps

1. Define the constructor function Student(name, marks) that saves name and marks on this.
2. Create the object student using new Student("Asha", 88).
3. Print the name and the marks with their labels, one on each line.

## Files

- README.md
- task1.html
- task1.js
- screenshot_task1.png

## How to run

Open task1.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Student Name: Asha and Student Marks: 88.
