# Experiment 7 — Task 2

## What it does

Create a Book class with a summary method and print one book's summary.

## Steps

1. Define the class Book with a constructor that saves title and pages.
2. Add the method summary() that returns the title, " has ", the pages and " pages".
3. Create the object book using new Book("Algorithms", 320).
4. Print book.summary().

## Files

- README.md
- task2.html
- task2.js
- screenshot_task2.png

## How to run

Open task2.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Algorithms has 320 pages.
