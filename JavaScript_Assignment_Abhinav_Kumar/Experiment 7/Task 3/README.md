# Experiment 7 — Task 3

## What it does

Add a result method to Student.prototype and check the student's marks.

## Steps

1. Define the constructor function Student(name, marks).
2. Add the method Student.prototype.result that returns "Pass" if marks >= 40, otherwise "Fail".
3. Create the object student using new Student("Asha", 88).
4. Print student.result().

## How to run

Open task3.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Pass.
