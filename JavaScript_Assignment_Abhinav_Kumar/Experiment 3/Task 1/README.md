# Experiment 3 — Task 1

## What it does

Assign a grade based on marks using if, else if, and else.

## Steps

1. Store 72 in marks.
2. If marks >= 75, print "Grade A".
3. Else if marks >= 60, print "Grade B".
4. Otherwise, print "Grade C".

## Files

- README.md
- task1.html
- task1.js
- screenshot_task1.png

## How to run

Open task1.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Grade B.
