# Experiment 3 — Task 3

## What it does

Use a while loop to add consecutive numbers until the total passes 20.

## Steps

1. Set total = 0 and i = 1.
2. While total <= 20: set total = total + i and increase i by 1.
3. Print total.

## Files

- README.md
- task3.html
- task3.js
- screenshot_task3.png

## How to run

Open task3.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints 21.
