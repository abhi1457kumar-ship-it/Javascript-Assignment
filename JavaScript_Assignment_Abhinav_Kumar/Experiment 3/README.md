# Experiment 3: Conditions and Loops

## Aim

To choose between cases with if, else if and else, and to repeat work with a for loop and a while loop.

## Software / Tools Required

Web browser (Google Chrome / Microsoft Edge / Firefox) with the developer console (F12); Node.js; a code editor such as VS Code.

## Theory

Conditions run a block of code only when a test is true: if checks the first test, else if checks further tests and else runs when no test is true. A for loop repeats code a fixed number of times using an initialisation, a condition and an update. A while loop repeats code as long as its condition is true, so the variables used in the condition must change inside the loop.

## Result

JavaScript programs were written to decide a grade using an else-if ladder, to print numbers with a for loop and to add numbers with a while loop.

## Viva-Voce Questions

1. What is the difference between a for loop and a while loop?
2. What are the three parts of a for loop?
3. How does an else-if ladder work?
4. What happens if the condition of a while loop never becomes false?
5. Why is the variable i increased inside the while loop?
