# Experiment 11 — Task 1

## What it does

Demonstrate how a block-scoped variable differs from an outer variable.

## Steps

1. Declare level = "outer".
2. Open a block, declare level = "inner" inside it and print level.
3. Close the block and print level again.

## Files

- README.md
- task1.html
- task1.js
- screenshot_task1.png

## How to run

Open task1.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints inner, then outer.
