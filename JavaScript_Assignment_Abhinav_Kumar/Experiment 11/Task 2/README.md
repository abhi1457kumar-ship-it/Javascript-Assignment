# Experiment 11 — Task 2

## What it does

Create a closure-based counter and print its value after two calls.

## Steps

1. Define makeCounter(): set count = 0 and return a function that increases count by 1 and returns it.
2. Store the returned function in counter.
3. Call counter() twice and print each result.

- README.md

## How to run

Open task2.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints 1, then 2.
