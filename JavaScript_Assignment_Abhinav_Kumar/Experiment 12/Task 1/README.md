# Experiment 12 — Task 1

## What it does

Pass a callback to applyTwice and add ten to a number two times.

## Steps

1. Define applyTwice(func, value): call func on value, then call func on the result, and return it.
2. Define addTen(num) that returns num + 10.
3. Call applyTwice(addTen, 5).
4. Print the result.

## How to run

Open task1.html in Chrome, Edge, or Firefox and press F12 to check the Console.

The console prints 25.
