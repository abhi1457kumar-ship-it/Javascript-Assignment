# Experiment 12 — Task 3

## What it does

Repeat a callback three times and print each round number.

## Steps

1. Define repeatAction(times, action): repeat for i = 1 to times and call action(i).
2. Call repeatAction with 3 and an arrow function that prints "Round " followed by the round number.

## Files

- README.md
- task3.html
- task3.js
- screenshot_task3.png

## How to run

Open task3.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Round 1, Round 2, and Round 3.
