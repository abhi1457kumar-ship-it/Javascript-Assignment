# Experiment 12 — Task 2

## What it does

Pass a formatting callback to display a mark out of 100.

## Steps

1. Define formatMarks(marks, callback) that returns callback(marks).
2. Call formatMarks with 76 and an arrow function that returns "Marks: ", the marks and "/100".
3. Print the result.

## Files

- README.md
- task2.html
- task2.js
- screenshot_task2.png

## How to run

Open task2.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Marks: 76/100.
