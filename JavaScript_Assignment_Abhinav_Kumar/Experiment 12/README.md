# Experiment 12: Callbacks and Higher-Order Functions

## Aim

To pass a function as an argument to another function and call it.

## Software / Tools Required

Web browser (Google Chrome / Microsoft Edge / Firefox) with the developer console (F12); Node.js; a code editor such as VS Code.

## Theory

In JavaScript, functions are values, so a function can be passed to another function as an argument. The function that is passed is called a callback, and a function that takes or returns another function is called a higher-order function. Callbacks make a function flexible, because the work done inside it can be changed by passing a different function.
