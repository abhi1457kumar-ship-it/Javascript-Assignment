# Experiment 13: Reduce, Some, Every and Map

## Aim

To use reduce, some, every and map on arrays, and to keep the original array unchanged.

## Software / Tools Required

Web browser (Google Chrome / Microsoft Edge / Firefox) with the developer console (F12); Node.js; a code editor such as VS Code.

## Theory

reduce() combines all the items of an array into one value using a function and a starting value. some() returns true if at least one item passes a test, and every() returns true only if all items pass the test. map() creates a new array by applying a function to every item. map() does not change the original array.
