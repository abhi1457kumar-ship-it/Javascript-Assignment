# Experiment 13 — Task 3

## What it does

Use map to increase marks while preserving and printing the original array.

## Steps

1. Create the array marks with 72, 85, 64 and 90.
2. Use map to create newMarks in which every mark is increased by 5.
3. Print newMarks.
4. Print the original marks array.

## Files

- README.md
- task3.html
- task3.js
- screenshot_task3.png

## How to run

Open task3.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints New Marks: [77, 90, 69, 95] and Original Marks: [72, 85, 64, 90].
