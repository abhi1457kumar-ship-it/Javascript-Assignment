# Experiment 13 — Task 2

## What it does

Use some and every to check mark thresholds.

## Steps

1. Create the array marks with 72, 85, 30 and 90.
2. Use some to check whether any mark is below 40 and store the answer in below40.
3. Use every to check whether all marks are 35 or more and store the answer in above35.
4. Print both answers with their labels.

## Files

- README.md
- task2.html
- task2.js
- screenshot_task2.png

## How to run

Open task2.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Any mark below 40: true and All marks are 35 or more: false.
