# Experiment 13 — Task 1

## What it does

Use reduce to total the prices in an array.

## Steps

1. Create the array prices with 120, 45 and 300.
2. Use reduce with the starting value 0 to add every price to the sum.
3. Print the total.

Open task1.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Total Price: 465.
