# Experiment 6 — Task 1

## What it does

Convert a student object to JSON text and print it.

## Steps

1. Create the object student with name "Rohan" and marks [70, 80].
2. Convert it to JSON text using JSON.stringify and store it in jsonText.
3. Print jsonText.

## Files

- README.md
- task1.html
- task1.js
- screenshot_task1.png

## How to run

Open task1.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints the JSON text {"name":"Rohan","marks":[70,80]}.
