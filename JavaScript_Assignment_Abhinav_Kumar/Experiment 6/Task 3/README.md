# Experiment 6 — Task 3

## What it does

Catch a JSON parsing error and print an invalid-data message.

## Steps

1. Store the text {name: Rohan} in jsonText.
2. Inside a try block, call JSON.parse on jsonText and print the result.
3. If parsing fails, the catch block runs and prints "Invalid JSON".

## Files

- README.md
- task3.html
- task3.js
- screenshot_task3.png

## How to run

Open task3.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Invalid JSON.
