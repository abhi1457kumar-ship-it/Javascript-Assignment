# Experiment 9 — Task 2

## What it does

Validate a name and report an error when it is blank.

## Steps

1. Define validateForm(name) and create an empty array errors.
2. If name is an empty string, add "Name is required" to errors.
3. Return errors.
4. Print validateForm("Asha") and then validateForm("").

## Files

- README.md
- task2.html
- task2.js
- screenshot_task2.png

## How to run

Open task2.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints an empty error array [], then ["Name is required"].
