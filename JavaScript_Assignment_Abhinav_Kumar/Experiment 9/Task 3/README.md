# Experiment 9 — Task 3

## What it does

Load and save a note with localStorage.

## Steps

1. Create a page with a text box (id note) and a Save button (id saveBtn).
2. When the page opens, read localStorage.getItem("note") and show it in the text box (or an empty text if nothing is saved).
3. When Save is clicked, store the text of the box in localStorage under the key "note".
4. Show an alert "Note Saved Successfully".

## Files

- README.md
- task3.html
- task3.js
- screenshot_task3.png

## How to run

Open task3.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The saved note is restored in the text box; Save stores the text and shows Note Saved Successfully.
