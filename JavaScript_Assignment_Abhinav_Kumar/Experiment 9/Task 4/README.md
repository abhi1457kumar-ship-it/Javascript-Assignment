# Experiment 9 — Task 4

## What it does

Check a multiple-choice answer and show feedback on the page.

## Steps

1. Create a page with the question "What is 2 + 3?", three radio buttons (4, 5, 6), the button "Check answer" (id checkBtn) and an empty paragraph (id result).
2. When the button is clicked, find the selected radio button using querySelector.
3. If a button is selected and its value is "5", show "Correct" in the result paragraph.
4. Otherwise, show "Try again".

## Files

- README.md
- task4.html
- task4.js
- screenshot_task4.png

## How to run

Open task4.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

Choosing 5 shows Correct; choosing 4 or 6 shows Try again.
