# Experiment 9 — Task 1

## What it does

Change a page heading when the user clicks a button.

## Steps

1. Create a page with the heading "Welcome" (id heading) and the button "Change text" (id changeBtn).
2. Get both elements using getElementById.
3. Add a click event listener to the button.
4. When the button is clicked, set the heading text to "Button clicked".

## Files

- README.md
- task1.html
- task1.js
- screenshot_task1.png

## How to run

Open task1.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The page heading changes from Welcome to Button clicked after the button is clicked.
