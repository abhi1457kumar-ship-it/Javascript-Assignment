# Experiment 14 — Task 3

## What it does

Use setInterval to print three ticks, then clear the interval.

## Steps

1. Set count = 0.
2. Use setInterval with 200 milliseconds: in each call increase count by 1 and print "Tick" with count.
3. When count is 3, stop the interval with clearInterval.

## Files

- README.md
- task3.html
- task3.js
- screenshot_task3.png

## How to run

Open task3.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Tick 1, Tick 2, then Tick 3.
