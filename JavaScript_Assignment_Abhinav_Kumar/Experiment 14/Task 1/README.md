# Experiment 14 — Task 1

## What it does

Compare synchronous output with a zero-delay setTimeout callback.

## Steps

1. Print "Start".
2. Use setTimeout with a delay of 0 to schedule a function that prints "Timer done".
3. Print "End".
4. Note the order in which the three lines appear.

## Files

- README.md
- task1.html
- task1.js
- screenshot_task1.png

## How to run

Open task1.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Start, End, then Timer done.
