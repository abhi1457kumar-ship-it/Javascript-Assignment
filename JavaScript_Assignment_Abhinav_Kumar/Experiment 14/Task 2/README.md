# Experiment 14 — Task 2

## What it does

Cancel a setTimeout callback before it prints.

## Steps

1. Use setTimeout with a delay of 1000 milliseconds to schedule the message "Not shown" and keep its id in timerId.
2. Cancel the timer with clearTimeout(timerId).
3. Print "Cancelled".

## Files

- README.md
- task2.html
- task2.js
- screenshot_task2.png

## How to run

Open task2.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Cancelled; the Not shown message is cancelled.
