# Experiment 1 — Task 1

## What it does

Load a JavaScript file from an HTML page and print a greeting in the browser console.

## Steps

1. Create an HTML page with a heading "My First JavaScript Script".
2. Add a script tag at the end of the body that loads task1.js.
3. In task1.js, print "Hello from the script" using console.log.
4. Open the page in a browser and check the console (F12).

## Files

- README.md
- task1.html
- task1.js
- screenshot_task1.png

## How to run

Open task1.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Hello from the script.
