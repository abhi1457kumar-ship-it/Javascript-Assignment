# Experiment 1: Your First JavaScript Script

## Aim

To run a script in the browser and with Node, and to declare values with const and let.

## Software / Tools Required

Web browser (Google Chrome / Microsoft Edge / Firefox) with the developer console (F12); Node.js; a code editor such as VS Code.

## Theory

JavaScript is the programming language of the web. A script can be added to an HTML page with the script tag, or run directly with Node.js. console.log() prints a value to the browser console (F12) or to the terminal. const declares a variable whose value cannot be reassigned, and let declares a variable whose value can change; The typeof operator returns the data type of a value, such as string, number or boolean.

## Tasks

| Task | One-line description | Files | How to run |
|---:|---|---|---|
| 1 | Load a JavaScript file from an HTML page and print a greeting in the browser console. | task1.html, task1.js, screenshot_task1.png | Open task1.html and press F12 |

| 3 | Use typeof to print the types of a string, a number, and a boolean. | task3.html, task3.js, screenshot_task3.png | Open task3.html and press F12 |

## Result

JavaScript programs were written to print text with console.log, to declare values with const and let, and to find the type of values using typeof.

## Viva-Voce Questions

1. What is the use of the script tag in an HTML page?
2. What is the difference between const and let?
3. What does console.log() do?
4. What does the typeof operator return?
5. How do you run a JavaScript file with Node.js?
