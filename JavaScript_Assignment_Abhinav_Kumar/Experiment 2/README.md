# Experiment 2: Operators, Type Conversion and a Calculator

## Aim

To use arithmetic operators, to convert between text and numbers, and to use if and else if to choose an operation.

## Software / Tools Required

Web browser (Google Chrome / Microsoft Edge / Firefox) with the developer console (F12); Node.js; a code editor such as VS Code.

## Theory

The arithmetic operators are +, -, *, / and %. JavaScript converts values between types: Number() converts text to a number and String() converts a value to text. When + is used with a number and a string, the values are joined (concatenation) instead of being added. The if and else if statements choose which block of code runs, and the strict equality operator === compares both value and type.

## Result

JavaScript programs were written to use arithmetic operators, to convert between text and numbers, and to choose an operation using if and else if.

## Viva-Voce Questions

1. What is the difference between == and ===?
2. How do you convert text to a number in JavaScript?
3. What happens when a number is added to a string using +?
4. Name the arithmetic operators in JavaScript.
5. What is the use of else if?
