# Experiment 2 — Task 3

## What it does

Use if/else-if to calculate addition and subtraction based on an operator.

## Steps

1. Declare a = 8, b = 4 and operator = "+".
2. If operator === "+", print a + b; else if operator === "-", print a - b.
3. Change operator to "-".
4. Repeat the same if and else if check.

## Files

- README.md
- task3.html
- task3.js
- screenshot_task3.png

## How to run

Open task3.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Result: 12, then Result: 4.
