# Experiment 2 — Task 2

## What it does

Convert text to a number and a number to text, then print the results.

## Steps

1. Convert the text "12" to a number using Number() and store it in num1.
2. Print num1 + 5.
3. Convert the number 7 to text using String() and store it in num2.
4. Print num2 joined with the text "3".

- README.md

## How to run

Open task2.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints 17, then 73.
