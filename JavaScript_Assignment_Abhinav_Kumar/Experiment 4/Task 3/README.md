# Experiment 4 — Task 3

## What it does

Apply the default tax rate to an amount and print the bill total.

## Steps

1. Define billWithTax(amount, taxRate = 0.18) that returns amount + (amount * taxRate).
2. Call billWithTax(100) without a tax rate, so the default 0.18 is used.
3. Print the result.

Open task3.html in Chrome, Edge, or Firefox and press F12 to check the Console.

The console prints 118.
