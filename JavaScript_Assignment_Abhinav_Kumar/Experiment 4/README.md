# Experiment 4: Writing Functions

## Aim

To write a function with a return value, an arrow function, and a default parameter.

## Software / Tools Required

Web browser (Google Chrome / Microsoft Edge / Firefox) with the developer console (F12); Node.js; a code editor such as VS Code.

## Theory

A function is a reusable block of code that can take parameters and return a value with the return statement. An arrow function is a shorter way to write a function using =>. A default parameter gives a parameter a value that is used when no argument is passed for it. A function runs only when it is called.

JavaScript programs were written using a function with a return value, an arrow function and a function with a default parameter.
