# Experiment 4 — Task 1

## What it does

Create and call a greet(name) function that returns a greeting.

## Steps

1. Define the function greet(name) that returns "Hello, " joined with name.
2. Call greet with the name "Asha".
3. Print the returned text.

## Files

- README.md
- task1.html
- task1.js
- screenshot_task1.png

## How to run

Open task1.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Hello, Asha.
