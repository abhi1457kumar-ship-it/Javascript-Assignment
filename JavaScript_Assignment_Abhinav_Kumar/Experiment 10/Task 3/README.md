# Experiment 10 — Task 3

## What it does

Use object destructuring to print a student's name and roll number.

## Steps

1. Create the object student with name "Rohan", roll 12 and marks 81.
2. Use object destructuring to take out name and roll.
3. Print name and roll, one on each line.

## Files

- README.md
- task3.html
- task3.js
- screenshot_task3.png

## How to run

Open task3.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Student Name: Rohan and Roll Number: 12.
