# Experiment 10 — Task 1

## What it does

Create a student object, read its name, update marks, and print the new marks.

## Steps

1. Create the object student with name "Rohan", roll 12 and marks 78.
2. Print student.name.
3. Change student.marks to 81.
4. Print student.marks.

## Files

- README.md
- task1.html
- task1.js
- screenshot_task1.png

## How to run

Open task1.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Student Name: Rohan and Updated Marks: 81.
