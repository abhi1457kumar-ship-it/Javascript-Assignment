# Experiment 10 — Task 2

## What it does

Use array destructuring to print the first two subjects.

## Steps

1. Create the array subjects with "Maths", "Science" and "English".
2. Use array destructuring to store the first two items in first and second.
3. Print first and second, one on each line.

## Files

- README.md
- task2.html
- task2.js
- screenshot_task2.png

## How to run

Open task2.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints First Subject: Maths and Second Subject: Science.
