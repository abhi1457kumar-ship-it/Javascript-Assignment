# Experiment 10: Objects and Destructuring

## Aim

To create an object, to read and change its properties, and to take values out of an array and an object with destructuring.

## Software / Tools Required

Web browser (Google Chrome / Microsoft Edge / Firefox) with the developer console (F12); Node.js; a code editor such as VS Code.

## Theory

An object stores data as property-value pairs and its properties are read or changed with the dot notation, such as student.name. Destructuring takes values out of an array or an object into separate variables. Array destructuring uses square brackets and follows the order of the items, and object destructuring uses curly brackets and matches the property names.
