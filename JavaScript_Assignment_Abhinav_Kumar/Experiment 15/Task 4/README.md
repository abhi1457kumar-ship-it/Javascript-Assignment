# Experiment 15 — Task 4

## What it does

Load a local user array asynchronously and print each user's name.

## Steps

1. Define getUsers() that returns a Promise which resolves after 100 milliseconds with an array of three users (id and name: Asha, Rohan, Meera).
2. Define the async function showUsers() that awaits getUsers().
3. Use forEach to print the name of each user.
4. Call showUsers().

## How to run

Open task4.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints Asha, Rohan, and Meera on separate lines.
