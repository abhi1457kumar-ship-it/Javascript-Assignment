# Experiment 15 — Task 1

## What it does

Resolve a Promise for valid marks and print the resolved value.

## Steps

1. Define checkMarks(marks) that returns a new Promise.
2. Inside it, if marks is between 0 and 100, resolve with marks; otherwise reject with Error("Marks out of range").
3. Call checkMarks(80) and use then to print the value.

## Files

- README.md
- task1.html
- task1.js
- screenshot_task1.png

## How to run

Open task1.html in Chrome, Edge, or Firefox and press F12 to check the Console.

## Expected output

The console prints 80.
